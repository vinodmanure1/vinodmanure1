CSV Format

The CSV file should have the following columns:

  • external_id: Unique question identifier
  • grade: Grade level (e.g., 9)
  • topic: Question topic/category
  • question_type: Type (mcq, true_false, rating)
  • question_text: The question text
  • options: JSON array of options (e.g., ["A","B","C"])
  • correct_answer: Correct answer
  • weight: Question weight (default: 1.0)
  • dimension: Assessment dimension (aptitude, logical, interest, motivation)
